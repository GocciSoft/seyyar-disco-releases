# Seyyar Disco — desktop installers

Download the latest build from the [Releases](https://github.com/Ahmet-Kirmizi/seyyar-disco-releases/releases/latest) page,
or from the download button on [seyyardisco.com](https://www.seyyardisco.com).

| Platform | File |
|---|---|
| macOS (Apple silicon) | `SeyyarDisco-mac-arm64.dmg` |
| macOS (Intel) | `SeyyarDisco-mac-x64.dmg` |
| Windows (x64) | `SeyyarDisco-win-x64.exe` |

Builds are currently unsigned: on macOS, right-click the app and choose **Open** the first time;
on Windows, choose **More info → Run anyway** in the SmartScreen prompt.

The source code lives in a private repository; this repo holds only release assets.
